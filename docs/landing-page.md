## 2. 页面分区说明

### 2.1 Navbar — 顶部导航

**功能：** 品牌展示、页面导航、登录注册入口

**组成元素：**
- Logo（图标 + 文字）
- 导航链接：首页、搜索行程、我的订单
- 操作按钮：登录、注册

**交互行为：**
- 页面初始：透明背景、白色文字（与 Hero 融合）
- 向下滚动 > 10px：白色背景 + 底部细线 + 毛玻璃效果
- Logo 颜色跟随：白色 → 品牌蓝

### 2.2 Hero — 品牌搜索区

**功能：** 3 秒内传达产品价值、引导用户开始搜索

**组成元素：**
- 背景层：深蓝渐变 + 微光粒子 + 城市天际线剪影
- 品牌区：飞机图标 + 主标题 + 副标题
- 搜索区：出发地 → 目的地 → 日期 → 搜索按钮
- 引导区：热门路线标签

**转化路径：**
用户看到标题 → 理解价值 → 输入城市 → 选择日期 → 点击搜索 → 跳转结果页

### 2.3 Trust Bar — 信任指标条

**功能：** 用数据建立信任、降低用户决策成本

**组成元素：**
- 4 个数据指标：覆盖城市、实时车次、满意率、响应速度
- 每项：图标 + 数字 + 说明文字
- 项间分隔线

**数据来源：**
- 覆盖城市 50+：基于 STATION_CODES 字典
- 实时车次 10000+：12306 每日车次总量
- 满意率 95%：目标值
- 响应速度 <1s：API 性能目标

### 2.4 Features — AI 功能亮点

**功能：** 展示产品核心差异化能力

**组成元素：**
- 区块标题 + 副标题
- 4 张功能卡片，每张包含：
  - 图标容器（64×64px 圆角方块）
  - 功能名称（H4）
  - 功能描述（Body）
  - 辅助说明（Caption）

**4 个功能点：**

| 功能 | 图标 | 标题 | 描述 |
|------|------|------|------|
| 智能评分 | Brain | 4 维度智能评分 | 时间·价格·耗时·舒适，综合分析推荐最优方案 |
| 实时数据 | Zap | 12306 实时抓取 | 直连官方数据源，车次·余票·价格实时同步 |
| 全网比价 | TrendingDown | 多平台价格对比 | 高铁·火车·飞机一站比价，找到最划算选择 |
| 精准匹配 | Clock | 出发时间匹配 | 输入期望时间，AI 精准推荐最近出发班次 |

### 2.5 Popular Destinations — 热门目的地

**功能：** 降低搜索门槛、引导用户快速进入搜索流

**组成元素：**
- 区块标题（左对齐）+ "查看全部"链接（右对齐）
- 横向滚动卡片容器
- 每张卡片：城市图片 + 城市名 + 最低价 + 车次数

**城市列表：**
上海、广州、成都、杭州、深圳、南京、武汉、西安、重庆、三亚

### 2.6 Social Proof — 社会证明

**功能：** 用真实数据和用户口碑增强可信度

**组成元素（上下两部分）：**

上半部分 — 数据展示：
- 大标题："AI 已为用户节省出行成本"
- 3 个数据卡片：搜索次数、平均节省金额、用户评分

下半部分 — 用户评价：
- 评价卡片（居中、可轮播）
- 引用文字 + 星级 + 用户信息
- 底部指示器

### 2.7 Footer — 页脚

**功能：** 品牌信息、法律声明、辅助导航

**组成元素：**
- 上部：Logo + 品牌标语 + 3 列链接
- 下部：版权信息 + 法律链接

## 6. 动画方案

### 6.1 页面加载动画

| 元素 | 动画 | 时长 | 缓动 | 延迟 |
|------|------|------|------|------|
| 主标题 | 淡入 + translateY(20px → 0) | 600ms | ease-out | 200ms |
| 副标题 | 淡入 + translateY(20px → 0) | 600ms | ease-out | 400ms |
| 搜索栏 | 淡入 + scale(0.95 → 1) | 600ms | ease-out | 600ms |
| 热门标签 | 逐个淡入 | 每个 100ms | ease-out | 800ms 起 |

### 6.2 持续动画

| 元素 | 动画 | 时长 | 缓动 | 循环 |
|------|------|------|------|------|
| 微光粒子 | 随机漂浮 (x/y ±50px) | 15-25s | linear | infinite |
| 光晕 1 | scale(1 → 1.1) + opacity 呼吸 | 8s | ease-in-out | infinite |
| 光晕 2 | scale(1.1 → 1) + opacity 呼吸 | 10s | ease-in-out | infinite |
| AI 标签 | 背景位置移动（微光流动） | 3s | linear | infinite |
| Logo 图标 | rotate(0° → 360°) | 20s | linear | infinite |

### 6.3 滚动触发动画

| 元素 | 动画 | 时长 | 缓动 | 触发条件 |
|------|------|------|------|----------|

| 功能卡片 | 淡入 + translateY(30px → 0) | 400ms | ease-out | 进入视口 20%、逐个 150ms |
| 目的地卡片 | 淡入 + translateX(30px → 0) | 400ms | ease-out | 进入视口 20%、逐个 100ms |
| 数据卡片 | 淡入 + translateY(20px → 0) | 400ms | ease-out | 进入视口 20% |
| 评价卡片 | 淡入 + scale(0.98 → 1) | 500ms | ease-out | 进入视口 20% |

- 形状：圆形、高斯模糊
- 大小：200-400px

### 8.3 目的地城市图片

```
用户打开页面
```

```
    ↓
选择日期
    ↓

```

## 11. 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| Hero 高度 | 520px | 足够容纳标题+搜索栏+标签，不浪费空间 |
| 搜索栏溢出 | 是 | Google Flights 风格、视觉焦点、首屏转化 |
| 信任指标 | 数字滚动 | Stripe 风格、数据驱动、建立信任 |
| 功能卡片 | 4 列 | 信息密度适中、对称美观 |
| 目的地滚动 | 横向 | 飞猪风格、移动端友好、节省空间 |
| Footer 颜色 | 深色 | Stripe 风格、与 Hero 呼应、视觉收尾 |
| 主色调 | 蓝+紫 | 科技+智能、区别于携程绿/飞猪橙 |
| 粒子效果 | 有 | 科技感、AI 感、品牌差异化 |
| 动画时长 | 200-600ms | 流畅不拖沓、符合 Material Design 规范 |
| 移动端搜索 | 垂直堆叠 | 操作方便、符合拇指热区 |
