# AI 智能行程助手 — UI 设计规范

> 参考风格：携程 · 飞猪 · Google Flights · Stripe  
> 定位：科技感 · 企业级 SaaS · 高端智能出行平台

---

## 1. Design System

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **智能感** | AI 推荐标签、动态评分、智能排序，让用户感知到"系统在思考" |
| **信息密度** | 借鉴携程：单屏展示更多有效信息，减少无意义留白 |
| **层级清晰** | 借鉴 Stripe：用色彩和阴影建立明确的视觉层级 |
| **操作直觉** | 借鉴 Google Flights：搜索 → 筛选 → 对比 → 预订，流程零学习成本 |
| **品牌调性** | 借鉴飞猪：年轻化但不幼稚，科技感但不冰冷 |

### 1.2 设计语言

- **圆角**：8px（卡片）、12px（按钮）、16px（弹窗）、999px（胶囊标签）
- **阴影**：3 层级体系（card / elevated / modal）
- **动效**：200ms ease-out（微交互）、300ms ease-in-out（页面转场）
- **图标**：Lucide Icons（线性风格，1.5px 描边）

## 3. 字体规范

### 3.1 字体栈

```css
--font-sans: 'Inter', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;
--font-display: 'Inter', 'Noto Sans SC', sans-serif;  /* 加粗用于标题 */
```

### 3.2 字号体系

| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Display | 48px / 3rem | 1.1 | 800 | Hero 标题 |
| H1 | 36px / 2.25rem | 1.2 | 700 | 页面标题 |
| H2 | 24px / 1.5rem | 1.3 | 700 | 区块标题 |
| H3 | 20px / 1.25rem | 1.4 | 600 | 卡片标题 |
| H4 | 18px / 1.125rem | 1.4 | 600 | 小标题 |
| Body Large | 16px / 1rem | 1.6 | 400 | 正文 |
| Body | 14px / 0.875rem | 1.5 | 400 | 次要正文 |
| Caption | 12px / 0.75rem | 1.4 | 400 | 标签、时间戳 |
| Tiny | 10px / 0.625rem | 1.3 | 500 | 角标、Badge |

### 3.3 价格字体

- 价格数字使用 **Tabular Numbers**（等宽数字）
- 货币符号 ¥ 使用 Body 字号，价格数字使用 H2 字号
- 原价使用 Gray 500 + 删除线

## 7. 组件库

## 14. 可访问性

- 对比度：所有文字 ≥ 4.5:1（WCAG AA）
- 焦点态：所有可交互元素有 2px Primary 色 outline
- 键盘导航：Tab 顺序符合视觉顺序
- 屏幕阅读器：所有图片有 alt 文字
- 颜色：不单独用颜色传达信息，配合图标/文字
